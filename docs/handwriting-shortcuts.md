# Handwriting shortcuts

A running list of what happens to each glyph when you write sitelen pona fast. Once the forms settle, this becomes the design for the handwriting font. Add to it whenever you notice something; rough notes are fine.

For each entry, note the shortcut and the feature that must survive it, so the glyph can't be confused with another one (see the confusables list in [custom-font-feasibility.md](custom-font-feasibility.md#font-1-handwriting--semi-cursive)).

| Word | Shortcut when writing fast | Must keep | Notes |
|---|---|---|---|
| *e* | one or two quick chevrons | the arrow direction | from the first handwriting sample |
| *o* | single loop | open loop, not a dot | must not collapse into *sina* |
