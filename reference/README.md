# Reference material

Binary font files and third-party drawings are not committed. Download them when needed:

- **jan Sonja's pu glyphs** (the official forms; reference layer of every template): `python3 build/fetch_pu_reference.py` puts them in `pu/downloads/` from Wikimedia Commons (files named "<Word> - sitelen pona in Sonja Lang's handwriting.svg"). Check each file's license on Commons before copying any into the repo.

- **sitelen seli kiwen** (jan Lepeka / Kreative Software, OFL 1.1, no Reserved Font Name): https://www.kreativekorp.com/software/fonts/sitelenselikiwen/
  Put the `.ttf` files in `reference/sitelen-seli-kiwen/downloads/` (ignored by git). Its README and license are kept here for reference.
